# CS077: Classes in Unity — Action 11A

## Overview
This project demonstrates 3D object manipulation in Unity using custom C# scripts to handle object translation, rotation, and color changing dynamically at runtime.

---

## Features & Scripts

* **`TranslateObject.cs`**  
  Handles smooth movement and positioning of 3D objects in world space along target axes.

* **`RotateObject.cs`**  
  Applies continuous rotation over time using transform manipulations based on specified speed and direction vectors.

* **`ChangeObjectColor.cs`**  
  Modifies object material properties dynamically at runtime to alter color parameters.
