## Video 2 / my learning and work

Video 2 – mini pipeline 2 GAME DEV mindset (Watch on YouTube)

Why Mindset Matters: Built on five pillars—creativity and innovation (combining familiar concepts with unique ideas), perseverance through long development cycles, adaptability to changing tech/trends, collaboration (even solo devs rely on engines and libraries), and customer focus (prioritizing player experience) [00:01].

Developing a Growth Mindset: Treat mindset as an ongoing process by actively embracing unfamiliar challenges, treating failures as iterative "beta" learning opportunities, focusing on effort over fixed talent, welcoming constructive feedback, finding positive role models, and continuously learning [04:07].

Common Obstacles & Solutions: Counter technical hurdles by keeping APIs/docs accessible and building a QA testing plan; stop scope creep by locking in an initial Game Design Document before adding features; start marketing/distribution early; secure funding via a clear business plan and pitch deck; and fight burnout through work-life balance, breaks, and community support [08:54].

Staying Motivated & Focused: Break large milestones into smaller tasks with clear deadlines, celebrate small wins to keep morale high, take regular breaks and protect sleep, stay organized with project management tools, stay passionate about the end goal, and prioritize constant team communication [16:28].

## Video 3 / my learning and work

Video 3 – Mini Pipeline 3 GAME DEV | Folders and File Creation Project (Watch on YouTube)

Why Folder Structure Matters: A well-planned directory layout improves efficiency, speeds up file access, simplifies onboarding, and keeps documentation and assets clear for solo devs, teams, or AI assistants [00:29].

Automated Project Logging (.LOG): Creating a plain text file with .LOG on the very first line causes Windows Notepad to automatically insert the current date and time every time the file is opened, making it easy to track development progress [02:26].

Custom JSON Folder & File Maker Utility: Demonstrates a custom tool ("Telera JSON Folder and FileMaker" via Pathways to Pipelines) that reads a JSON template to automatically generate nested folders, README files (.txt or .html), and a Game Development Document (GDD) template [05:39].

Essential Project Directories: Uses a pre-configured Unity game JSON structure containing dedicated folders for Context, Unity Project, Requirements (backstory and concept), Resources (project logs and tool links for Unity, Blender, Notepad++, Visual Studio, and Discord), Assets (audio, images, models, exports), and Study [14:34].

## Video 5 / my learning and work

Video 5 – mini pipeline 5 GAME DEV IntroToUnity (Watch on YouTube)

Project Setup & Template: Creates a new 3D project named Templer inside the project folder using Unity version 2021.3.21f1 and downloads the pre-configured Third Person Core starter template [01:25].

Troubleshooting File Path Lengths: Explains that decompressing/loading errors in Unity Hub often occur due to Windows MAX_PATH limits exceeding 256 characters, resolved by moving the project directly into a shorter directory root (e.g., D:\) [03:04].

Unity Interface Overview: Demonstrates how to dock and rearrange the core workspace tabs: Hierarchy (all active scene objects), Scene View (viewport where objects are constructed), Game View (active player perspective), Inspector (component properties like transforms, colliders, and mesh renderers for selected items), and Project/Assets tab (underlying project folder hierarchy) [06:00].

Scene Navigation Controls: Covers viewport shortcuts using a three-button mouse: scroll wheel to zoom [09:20], Alt + Left Click to orbit/rotate [09:40], Alt + Right Click for fine zooming [09:50], Alt + Middle Click to pan [10:07], and pressing F to focus directly on a selected object [10:36].

Playtesting Starter Controls: Demonstrates entering Play Mode to control the starter character using W, A, S, D for movement, mouse for camera rotation, Shift to sprint, and Space to jump, pressing Esc to unlock the cursor and exit [11:32].

## Video 6 / my learning and work

Video 6 – mini pipeline 6 GAME DEV import custom player (Watch on YouTube)

Asset Sourcing & Organization: Downloads a free humanoid character model (FBX) from Mixamo and uses the Telstra JSON Folder Maker to generate a structured subdirectory inside Unity's Assets folder under the project title, preventing third-party packages from cluttering the root [00:43].

Model Rig & Material Setup: Changes the imported FBX animation type to Humanoid in the Rig tab [14:26] and updates Material settings to Standard (Legacy) with external materials to resolve gray textures and apply normal maps [15:17].

Prefab Concept & Usage: Explains prefabs using a "cookie cutter" analogy—reusable template assets where updating the base prefab updates all scene instances while saving memory [16:24].

Replacing the Player Character: Unpacks the starter PlayerArmature prefab completely [22:47], deletes the default Armature_Mesh under Geometry [23:13], nests the new custom character mesh inside Geometry [23:25], and assigns the imported character's avatar to the Animator component [24:04].

Level Prototyping: Demonstrates duplicating scene objects and terrain meshes using Ctrl + D and translating them with the move tool (W) to expand the playable arena [25:01].

## Video 7 / my learning and work

Video 7 – Unity - Mini Pipeline 7 GAME DEV: Blender 3D (Watch on YouTube)

Blender Integration in the Pipeline: Introduces Blender 3D (v3.3.1) as the open-source modeling tool to create custom interactive assets—specifically a collectible coin—rather than relying solely on pre-made external assets [00:35].

Industry Compatible Keymap & Viewport Navigation: Configures Preferences (Edit > Preferences > Keymap) to Industry Compatible (Maya scheme) so navigation matches industry standards: Alt + LMB to orbit/rotate, Alt + MMB to pan, and Alt + RMB or scroll wheel to zoom [05:42].

Core Transform & Sub-Object Modes: Uses standard transform shortcuts—W (Translate), E (Rotate), and R (Scale)—alongside component selection modes: 1 for Vertices, 2 for Edges, 3 for Faces, and 4 for Object Mode [12:59].

Coin Modeling Workflow: Starts by creating a flat 3D Cylinder primitive, renames it to coin in the Scene Collection outliner [17:20], applies a outer edge Bevel to round the top and bottom borders [18:38], and uses Extrude Region scaled slightly inward (R) to produce recessed face rims on both sides [19:43].

## Video 8 / my learning and work

Video 8 – mini pipeline 8 GAME DEV Blender Adding textures (Watch on YouTube)

Material Setup & Viewport Display: Adds a new material slot on the coin in the Material Properties panel (renamed to coinBaseMaterial using camelCase) and switches the viewport display to Material Preview / Shading Mode so colors and textures render properly [00:26].

Connecting Texture Maps: Explains node input indicators—yellow dots accept inputs/textures, gray dots accept numeric scalar values (such as Metallic from 0 to 1), and purple dots accept 3D vectors—connecting an Image Texture node to the Base Color input [02:42].

UV Unwrapping & Island Alignment: Navigates to the UV Editing workspace to correct texture projection; selects the coin's front and rear face regions, executes an unwrap from the top Z-axis view, and scales (R) and moves (W) the UV islands directly over the coin artwork to eliminate distortion [04:47].

Edge Seam Cleanup & Texture Sourcing: Selects the rim border faces around the coin and moves their UV coordinates to a neutral, clean section of the texture sheet to prevent side-stretching, noting that free PBR textures can be downloaded from resources like ambientCG.com [08:13].

Exporting FBX to Unity: Enters Object Mode, navigates to File > Export > FBX, sets the export destination to the project assets folder, checks Selected Objects, and limits the exported object type strictly to Mesh (excluding cameras and lights) [10:07].

## Video 9 / my learning and work

Video 9 – mini pipeline 9 GAME DEV FinalCode (Watch on YouTube)

FBX Embedded Textures in Blender: To ensure textures import cleanly into Unity and allow extracting textures directly, set FBX export Path Mode to Copy and enable the Embed Textures button in Blender before exporting [01:05].

C# Script Architecture & Variables: Creates a coin C# script containing an AudioSource, a serialized AudioClip, and a continuousRotate boolean; explains that [SerializeField] preserves private variables within scene/prefab files and exposes them cleanly in the Inspector [03:57].

Rotation & Collection Logic: Uses transform.Rotate(Vector3.up * angle) inside Update() for steady spinning, and OnTriggerEnter(Collider other) to trigger audioSource.PlayOneShot() and Destroy() the child mesh/base on collision without clipping the sound prematurely [06:22].

Prefab Hierarchy & Collider Setup: Nests a Point Light and the mesh (renamed base) under an empty parent object coin, attaches the script, adds a Sphere Collider with Is Trigger enabled, and hooks up the downloaded pickup audio clip [10:15].

Prefab Overrides & Pipeline Completion: Emphasizes that scene-instance adjustments (colliders, scripts, rotation toggles) must be propagated across all future instances using Overrides > Apply All, completing the full pipeline from folder setup to functional gameplay [18:48].
